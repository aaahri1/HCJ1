# Video to GIF

동영상을 브라우저에서 바로 GIF 애니메이션으로 변환하는 웹 애플리케이션입니다. 서버 업로드 없이 모든 처리(프레임 추출, GIF 인코딩)가 클라이언트(브라우저)에서 이루어집니다.

## 주요 기능

- 좌상단 로고 클릭 시 [nanalab.kr](https://nanalab.kr)로 이동
- 드래그 앤 드롭 또는 버튼 클릭으로 동영상 파일 업로드 (다중 업로드 지원)
- 업로드된 파일마다 썸네일 + 진행률 표시줄 표시
- 변환 완료(100%) 시 GIF 다운로드 버튼 활성화
- GIF는 최대 29FPS로 제한되어 변환 시간이 지나치게 길어지지 않음
- 처리 속도를 위해 해상도는 최대 가로 480px, 프레임 수는 최대 150장으로 자동 제한

## 실행 방법

브라우저 보안 정책상 `file://`로 직접 열면 GIF 인코딩 워커 스크립트가 로드되지 않을 수 있으므로, 로컬 서버로 실행하는 것을 권장합니다.

```bash
cd /Users/ahri/Desktop/K-move/0914/08
python3 -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000` 접속.

## 사용 방법

1. 화면 중앙의 업로드 영역에 동영상 파일을 드래그 앤 드롭하거나 "파일 업로드" 버튼으로 선택합니다.
2. 파일 목록에 썸네일과 진행률 표시줄이 나타나며 자동으로 변환이 시작됩니다.
3. 진행률이 100%가 되면 "다운로드" 버튼이 나타나고, 클릭하면 GIF 파일을 저장할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 구조 |
| `style.css` | 스타일(다크 테마) |
| `script.js` | 업로드, 프레임 추출, GIF 인코딩 로직 |
| `libs/gif.js`, `libs/gif.worker.js` | GIF 인코딩 라이브러리 ([gif.js](https://github.com/jnordberg/gif.js), 오프라인 번들) |
| `logo.png` | 헤더 로고 이미지 |

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크 없음, 빌드 과정 없음)
- `<video>` + `<canvas>`로 동영상 프레임을 캡처
- [gif.js](https://github.com/jnordberg/gif.js)로 캡처한 프레임을 GIF로 인코딩 (Web Worker 사용)

## 제한 사항

- 모든 변환이 브라우저에서 이루어지므로 매우 긴 동영상이나 고해상도 영상은 자동으로 프레임 수/해상도가 축소됩니다.
- GIF 포맷은 지연시간을 10ms 단위로만 저장할 수 있어, 실제 재생 속도는 29FPS 이하로 반올림(내림 처리)되어 저장됩니다.
- 브라우저가 지원하는 동영상 코덱(mp4, webm 등)만 업로드할 수 있습니다.
