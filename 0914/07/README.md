# Smart Image Resizer (스마트 이미지 리사이저)

**Smart Image Resizer**는 사진의 왜곡 없이 원하는 종횡비(1:1, 3:4, 4:3, 9:16, 16:9, 커스텀)에 맞춰 여백 채우기(Padding) 또는 잘라내기(Crop)를 통해 이미지를 손쉽게 리사이징하고, 대기열 프로그레스 바를 통한 진행률 확인 및 일괄 ZIP 다운로드를 지원하는 모던 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **상단 브랜드 헤더**
   - 상단 좌측: **NanaLab 로고(`logo.png`)** 배치 및 클릭 시 [NanaLab 공식 홈페이지](https://nanalab.kr)로 이동
   - 상단 우측: **Smart Image Resizer** 타이틀 및 식별 뱃지

2. **다양한 종횡비(Aspect Ratio) 프리셋 & 커스텀**
   - **1:1**: 인스타그램 피드, 프로필 사진
   - **3:4**: 세로 인물 사진, 피드 표준
   - **4:3**: 전통적인 사진/디스플레이 표준
   - **9:16**: 인스타그램 스토리, 릴스, 유튜브 쇼츠, 틱톡 세로 풀스크린
   - **16:9**: 유튜브 썸네일, PC 와이드 모니터
   - **커스텀 (Custom)**: 가로:세로 비율 직접 입력 지원 (예: 5:7, 2:3 등)

3. **스마트 변환 모드**
   - **여백 채우기 (Padding)**: 원본 사진의 내용이 잘리지 않고 100% 온전히 보존되도록 캔버스 안에 배치하고, 남는 공간은 사용자가 선택한 여백 색상으로 깔끔하게 채웁니다.
     - **여백 색상 커스텀**: 기본값 흰색(`#FFFFFF`), 검정색, 슬레이트 다크, 소프트 그레이, 웜 베이지 프리셋 및 정밀 컬러 피커/HEX 입력 지원
     - **투명 배경 지원**: 투명(Transparent) 선택 시 자동으로 알파 채널이 보존되는 PNG 포맷으로 전환
   - **자르기 (Crop)**: 사진이 대상 캔버스를 꽉 채우도록 확대하며, 중앙을 기준으로 초과 영역을 자연스럽게 크롭합니다.

4. **드래그 앤 드롭 & 다중 파일 업로드**
   - 드래그 앤 드롭 존 및 '사진 파일 선택하기' 버튼 제공
   - 다중 파일(JPG, PNG, WEBP, GIF, SVG, BMP 등)을 한 번에 추가 가능
   - '샘플 이미지로 체험' 버튼으로 별도 파일 준비 없이도 즉시 기능 테스트 가능

5. **실시간 프로그레스 바 & 상태 표시**
   - 업로드된 이미지마다 썸네일과 원본 해상도, 변환 해상도, 모드가 표시됩니다.
   - 각 썸네일 옆에 **프로그레스 바(0% → 100%)**가 부드럽게 차오르며 작업 진행률을 실시간 시각화합니다.
   - 100% 완료 시 상태 뱃지가 '완료'로 변경되며 개별 다운로드 버튼이 활성화됩니다.

6. **개별 다운로드 & 전체 일괄 ZIP 다운로드**
   - **개별 다운로드**: 각 카드의 '다운로드' 버튼 또는 '상세 미리보기' 모달에서 즉시 다운로드 가능
   - **일괄 다운로드 (.ZIP)**: 대기열의 모든 이미지 처리가 100% 완료되면 일괄 다운로드 버튼이 활성화되며, `JSZip`을 통해 압축된 단일 `.zip` 파일로 모든 결과물을 한 번에 다운로드합니다.

7. **상세 비교 미리보기 모달**
   - 카드 썸네일이나 미리보기(눈 아이콘) 버튼을 클릭하면 원본과 리사이즈 결과물을 나란히 비교할 수 있는 팝업 모달을 제공합니다.

8. **출력 포맷 및 해상도 제어**
   - 출력 포맷: 원본 포맷 유지, PNG, JPEG, WebP 지원
   - 해상도 제어: 원본 고화질 유지(Auto), Full HD(1080p), 2K(1440p), 4K(2160p)

## 🚀 실행 방법

본 프로젝트는 순수 HTML, CSS, JavaScript로 제작되어 별도의 복잡한 빌드나 데이터베이스 없이 웹 브라우저에서 바로 구동 가능합니다.

### 1. 로컬 웹 서버 실행 (권장)

브라우저의 보안 정책(CORS 및 로컬 파일 접근 제한)으로 인해 웹 서버를 통해 실행하는 것을 권장합니다.

```bash
# Python을 사용하는 경우
python3 -m http.server 8080

# 또는 Node.js npx serve를 사용하는 경우
npx serve .
```

실행 후 브라우저에서 `http://localhost:8080`으로 접속하시면 됩니다.

## 💡 사용 방법

1. 브라우저에서 웹 애플리케이션을 엽니다.
2. 원하는 **캔버스 비율** (1:1, 3:4, 4:3, 9:16, 16:9, 또는 커스텀)을 선택합니다.
3. 변환 모드로 **여백 채우기 (Padding)** 또는 **자르기 (Crop)**를 선택합니다.
   - 여백 채우기를 선택한 경우, 원하는 여백 색상(기본 흰색)을 지정합니다.
4. 이미지들을 중앙 드롭존에 끌어다 놓거나 '사진 파일 선택하기' 버튼으로 추가합니다. (체험을 원하시면 '샘플 이미지로 체험'을 클릭)
5. 업로드된 이미지들의 프로그레스 바가 100%까지 차오르는 것을 확인합니다.
6. 완료된 이미지를 개별로 다운로드하거나, 우측 상단의 **'일괄 다운로드 (.ZIP)'** 버튼을 눌러 압축 파일로 한 번에 다운로드합니다.
