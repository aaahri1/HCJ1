# 💍 드미트리 & 로렐라이 모바일 청첩장

> **"Always be with you"**  
> 2099년 12월 26일 토요일 오후 12시, 나나컨벤션센터 2층 플로렌스홀  
> 두 사람의 영원한 사랑과 새로운 시작을 축복하는 프리미엄 모바일 청첩장 웹 페이지입니다.

---

## 📱 주요 특징 및 기능

### 1. 모바일 최적화 (Mobile-First UI/UX)
- 스마트폰 해상도(375px ~ 430px)에 최적화된 유려하고 반응성 높은 인터페이스
- 데스크톱/태블릿 접속 시 모바일 프레임과 은은한 배경으로 스마트폰 화면 그대로 감상 가능
- 부드러운 스크롤 페이드인 인터랙션 (`IntersectionObserver`)

### 2. 실시간 디데이 & 카운트다운 애니메이션
- 예식 일시(**2099년 12월 26일 12:00:00**)까지 남은 시간을 일(DAYS), 시(HOURS), 분(MINS), 초(SECS) 단위로 실시간 계산
- 1초 단위로 부드럽게 박동하는 초 펄스 애니메이션
- 2099년 12월 미니 캘린더 연동 (26일 토요일 웨딩마치 하트 강조)

### 3. 초대 문구 및 양가 혼주 안내 (`문구.txt` 반영)
- 서약의 아름다운 시적 문구 반영
- 양가 부모님 및 신랑/신부 관계도 표시
  - 루크사트 · 파르벤의 아들 **드미트리**
  - 마키아토 · 페르시카의 딸 **로렐라이**

### 4. 신랑 · 신부 연락하기 버튼 및 모달
- **"지금 신랑에게 연락하세요"**, **"지금 신부에게 연락하세요"** 원클릭 버튼
- 탭 시 신랑/신부 및 양가 부모님께 전화 걸기(`tel:`) 및 축하 문자 보내기(`sms:`)를 선택할 수 있는 감성 팝업 모달 제공

### 5. 포토 갤러리 & 풀스크린 라이트박스
- 제공된 5종의 고화질 웨딩 사진 연동 (`pictures/함께1.png`, `신랑.png`, `신부.png`, `함께2.png`, `함께3.png`)
- 사진 터치 시 전체 화면 라이트박스 확대 모달
- 좌우 화살표, 키보드 방향키, 모바일 터치 스와이프 제스처(Swipe Left/Right) 지원

### 6. 오시는 길 & 내비게이션 바로가기
- 나나컨벤션센터 2층 플로렌스홀 위치 안내 및 예식장 주소 1초 복사
- 네이버지도, 카카오맵, 티맵 빠른 길찾기 링크 연동
- 지하철(강남역/신논현역), 버스, 자가용 및 주차 안내 상세 카드

### 7. 마음 전하시는 곳 (축의금 계좌 안내 & 복사)
- 아코디언 토글 형태의 깔끔한 수납식 카드
  - **신랑측**: 샤드은행 `100-0000-00000` (예금주: 파르벤)
  - **신부측**: 크레딧은행 `100-0000-0000` (예금주: 페르시카)
- **[복사하기]** 클릭 시 원클릭 클립보드 복사 및 하단 토스트 알림 노출

### 8. 축하 메시지 방명록 (Guestbook)
- 하객이 성함, 관계, 축하 메시지를 작성하여 즉시 등록
- 브라우저 로컬 스토리지(`localStorage`)에 저장되어 새로고침 후에도 메시지 영구 보존

### 9. 청첩장 공유 및 감성 요소
- 카카오톡 공유 및 청첩장 URL 주소 복사
- 배경에 은은하게 흩날리는 벚꽃/장미 꽃잎 애니메이션 (Canvas API)
- 낭만적인 오르골/하프 멜로디 BGM 온/오프 컨트롤러 (Web Audio API 탑재로 별도 음원 파일 없이 동작)

```
│   └── 함께3.png     # 웨딩 스냅 사진 3

└── README.md        # 프로젝트 안내 문서
```

## 🚀 실행 및 확인 방법

### 방법 1. 웹 브라우저에서 바로 열기
1. 작업 폴더 내의 `index.html` 파일을 더블 클릭하거나,
2. Chrome, Safari, Edge 등 브라우저 창으로 드래그 앤 드롭하여 바로 확인하실 수 있습니다.

### 방법 2. 로컬 웹 서버 실행 (스마트폰 기기 직접 테스트 가능)
터미널에서 아래 명령어로 간이 웹 서버를 구동할 수 있습니다:

```bash
# Python 3 내장 서버 구동 (포트 8088)
python3 -m http.server 8088
```

- **PC 접속**: 브라우저 주소창에 `http://localhost:8088` 입력
- **모바일 접속**: PC와 동일한 Wi-Fi에 연결된 스마트폰 브라우저에서 `http://[PC_IP_주소]:8088` 입력

## 🛠 사용 기술 스택
- **HTML5**: 웹 접근성 및 SEO 메타 태그(OpenGraph), 모바일 뷰포트 최적화
- **Vanilla CSS3**: CSS 변수(Variables), Flexbox, CSS Grid, 부드러운 트랜지션 및 키프레임 애니메이션
- **Vanilla JavaScript (ES6+)**: `requestAnimationFrame`, `IntersectionObserver`, `Web Audio API`, `Canvas 2D`, `Clipboard API`, `localStorage`
- **외부 종속성(Dependency)**: 무거운 라이브러리(jQuery, Tailwind 등) 없이 순수 웹 표준 기술로만 가볍고 빠르게 로딩되도록 구현되었습니다.
