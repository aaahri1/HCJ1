# 🗜️ Smart Doc Compressor

> **실제 용량 최적화가 가능한 오피스 문서(PPTX, DOCX)를 브라우저에서 안전하고 빠르게 압축하는 스마트 웹 애플리케이션**

![Smart Doc Compressor Header](logo.png)

---

## 📌 프로젝트 소개

**Smart Doc Compressor**는 사용자가 브라우저에서 대용량 프레젠테이션 및 문서 파일의 실제 용량을 안전하게 줄일 수 있도록 제작된 웹 애플리케이션입니다.

외부 서버로 파일을 전송하지 않고 **순수 브라우저 메모리 상에서 실제 OpenXML 패키지를 분석하여 포함된 고용량 미디어(이미지) 및 텍스트 스트림을 직접 재압축(DEFLATE Level 9)**합니다.

---

## 🎯 지원 포맷 및 업로드 정책 안내

본 앱은 **실제 용량 축소(True Compression)**가 보장되는 포맷만을 업로드하도록 엄격하게 필터링합니다:

| 포맷 | 확장자 | 압축 지원 여부 | 안내 사항 |
|:---:|:---:|:---:|:---|
| **파워포인트** | `.pptx` | ✅ **업로드 및 실제 압축 지원** | 슬라이드 내 고해상도 이미지 다운샘플링 & XML 스트림 최대 압축 |
| **워드 문서** | `.docx` | ✅ **업로드 및 실제 압축 지원** | 문서 내 삽입 이미지 최적화 & OpenXML 패키지 최대 압축 |
| **전자문서** | `.pdf` | ⛔ **업로드 차단** | 브라우저 환경에서 폰트/벡터 손실 없는 실제 압축 불가로 업로드 제한 |
| **한글 문서** | `.hwp` | ⛔ **업로드 차단** | 한글과컴퓨터 독점 바이너리 포맷으로 브라우저 내 재압축 불가로 업로드 제한 |
| **구버전 오피스** | `.ppt`, `.doc` | ⛔ **업로드 차단** | 구형 바이너리 포맷(최신 .pptx, .docx 포맷으로 저장 후 업로드 권장) |

> [!NOTE]
> 브라우저 상에 PDF나 HWP 파일을 드래그하거나 선택할 경우, 경고 애니메이션과 함께 **"⛔ 업로드 차단"** 알림이 표시되며 큐에 등록되지 않습니다.

## ✨ 핵심 기능

1. **실제 용량 축소 엔진 (JSZip + HTML5 Canvas)**
   - 문서 내부의 고용량 이미지를 추출하여 스마트 리샘플링 및 품질 최적화를 수행합니다.
   - 내부 XML 데이터 스트림을 DEFLATE Level 9로 최적 패키징하여 실제 파일 크기를 대폭 절감합니다.

2. **파일별 독립 비동기 처리 & 실시간 프로그레스 바**
   - 여러 개의 파일을 동시에 등록해도 각 파일마다 **독립적인 작업 파이프라인**이 실행됩니다.
   - 각 파일 카드별로 `0%`부터 `100%`까지 실시간 진행률과 단계별 상태(구조 분석 → 미디어 압축 → XML 스트림 압축 → 패키징)를 시각적으로 확인할 수 있습니다.

3. **스마트 파일명 네이밍 규칙 적용 (`compressed 원본파일명`)**
   - 압축이 완료되면 우측의 **다운로드** 버튼이 활성화됩니다.
   - 다운로드 시 파일명은 원본과 즉시 구분할 수 있도록 **`compressed 원본파일명`** 형식으로 자동 저장됩니다.
     - *예시: `회사소개서.pptx` → `compressed 회사소개서.pptx`*
     - *예시: `기획제안서.docx` → `compressed 기획제안서.docx`*

4. **압축 모드 선택 & 통계 요약**
   - **균형 모드**: 이미지 품질 75% 유지 + DEFLATE 최대 압축 (권장)
   - **최대 압축 모드**: 이미지 해상도 조정 + 고압축 55% 품질 (대용량 파일용)
   - **무손실 모드**: 원본 이미지 품질 유지 + XML 스트림 압축
   - 전체 절감 용량 계산 및 일괄 다운로드(전체 다운로드) 기능 지원

5. **브랜딩 및 바로가기 연동**
   - 좌상단 **나나컴퍼니 로고**(`logo.png`) 클릭 시 [https://nanalab.kr](https://nanalab.kr)로 즉시 이동합니다.

## 🚀 실행 방법

### 방법 1. 파이썬 로컬 서버 실행 (권장)
터미널에서 해당 프로젝트 폴더로 이동 후 아래 명령어를 실행합니다:

```bash
# Python 3 로컬 서버 실행
python3 -m http.server 3456
```
브라우저에서 `http://localhost:3456` 주소로 접속합니다.

### 방법 2. 일반 브라우저로 바로 열기
`index.html` 파일을 더블 클릭하여 크롬, 사파리, 엣지 등 최신 웹 브라우저에서 바로 실행할 수 있습니다. (로컬 `jszip.min.js`가 내장되어 있어 인터넷 연결 없이도 정상 작동합니다.)
