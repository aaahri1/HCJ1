# KOREA JOURNEY | 일본인 대상 한국 관광 안내 웹사이트

일본인 여행객을 대상으로 서울, 부산, 제주도 등 대표 명소와 최신 트렌드, K-FOOD, 그리고 실전 여행 준비 정보(WOWPASS, 교통, 통신 등)를 제공하는 반응형 관광 포털 웹사이트 프로젝트입니다.

---

## 1. 프로젝트 개요

- **목적**: 일본인 관광객이 언어와 결제 등의 부담 없이 안심하고 한국을 여행할 수 있도록 돕는 실용적인 정보 제공
- **핵심 특징**:
  - 일본인 사용자에 최적화된 자연스러운 일본어 콘텐츠 구성 (HTML `lang="ja"`)
  - W3C 웹 표준 및 WAI-ARIA 접근성 가이드라인 준수
  - Tailwind CSS를 활용한 모던 유틸리티 스타일링 및 반응형 디자인 (모바일, 태블릿, PC 완벽 대응)
  - jQuery 및 Vanilla JavaScript 기반의 경량 인터랙션 (고정 헤더 블러, 햄버거 메뉴, 실시간 탭 필터, 아코디언 FAQ)
  - 이모지를 일절 배제하고 정밀한 SVG 벡터 아이콘 및 정돈된 텍스트 배지 채용

---

## 2. 기술 스택

- **마크업**: HTML5 (시맨틱 태그 구조)
- **스타일링**: CSS3, Tailwind CSS (CDN), Google Fonts (Noto Sans JP)
- **스크립트**: JavaScript (ES6+), jQuery 3.7.1
- **에셋**: 고해상도 관광지 실사 사진 (서울 경복궁, 부산 해운대, 제주 성산일출봉, 전통 한식)

## 4. 주요 기능 및 페이지 구성

1. **헤더 & 글로벌 네비게이션 (GNB)**
   - 스크롤 이동 시 반투명 블러 및 그림자 효과 자동 적용
   - 모바일 환경 대응 햄버거 토글 메뉴
2. **히어로 섹션 (Hero Section)**
   - 경복궁 야경 파노라마를 배경으로 한 대표 헤드카피와 바로가기 CTA 버튼
3. **핵심 요약 배너 (Highlights)**
   - 비행시간(최단 2시간대), 완전 캐시리스(WOWPASS), 24시간 일본어 통역 안내(1330), 무비자 입국 등 핵심 팩트 전달
4. **인기 지역 소개 (Popular Destinations)**
   - 서울, 부산, 제주도의 특장점 소개 카드
   - 실시간 카테고리 필터링 탭 기능
5. **여행 필수 준비 가이드 (Travel Essentials)**
   - WOWPASS 결제, eSIM 데이터 통신, NAVER 지도 앱 활용법, 1330 무료 통역 콜센터 안내
6. **K-FOOD & 문화 체험 쇼케이스**
   - 삼겹살, 무료 반찬 문화, 성수동 카페 거리, 한복(치마저고리) 고궁 무료입장 혜택 안내
7. **자주 묻는 질문 (FAQ)**
   - 일본어 통용 수준, 현금 환전 권장 금액, 팁 문화 유무, 1인 여행(혼밥) 안정성 관련 아코디언 Q&A
8. **여행 상담 및 문의 폼**
   - 입력 유효성 검사 및 전송 완료 피드백 알림

## 5. 실행 방법

별도의 번들러나 패키지 설치 과정 없이 `index.html` 파일을 웹 브라우저에서 직접 열거나, 로컬 웹 서버를 통해 즉시 실행할 수 있습니다.

```bash
# Python 내장 웹 서버 실행 예시
python3 -m http.server 8080
```

서버 실행 후 브라우저에서 `http://localhost:8080` 으로 접속하여 확인합니다.
