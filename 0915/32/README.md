# 🎵 오디오 편집기 (Audio Editor)

브라우저에서 바로 동작하는 오디오 편집 웹 앱입니다. 서버, 빌드 도구, 별도 설치 없이
MP3 / WAV 파일을 업로드해서 **포맷 변환**, **볼륨 조절**, **구간 트림(Trim)** 을 할 수 있습니다.
모든 처리는 [Web Audio API](https://developer.mozilla.org/ko/docs/Web/API/Web_Audio_API)를 이용해
사용자의 브라우저 안에서만 이루어지며, 파일이 외부 서버로 전송되지 않습니다.

## 주요 기능

1. **포맷 변환**: 업로드한 오디오를 **WAV**(무손실 PCM) 또는 **MP3**(128 / 192 / 320 kbps)로 내보내기
2. **볼륨 조절**: 슬라이더로 0~200% 범위에서 실시간 미리듣기 후, "적용" 버튼으로 실제 오디오 데이터에 반영
3. **구간 트림**: 파형을 보면서 시작/끝 핸들을 드래그하거나 시간 직접 입력으로 원하는 구간만 잘라내기
4. 파형 시각화, 재생/일시정지/정지, 파형 클릭으로 탐색(seek), 원본으로 되돌리기

## 실행 방법

빌드 과정이 없는 순수 정적 웹 앱(HTML/CSS/JS)입니다. 아래 중 편한 방법으로 실행하세요.

### 방법 A. 로컬 서버로 실행 (권장)

일부 브라우저는 `file://` 로 직접 열었을 때 오디오 디코딩 관련 API를 제한할 수 있으므로,
간단한 정적 서버로 여는 것을 권장합니다.

```bash
# 이 프로젝트 폴더에서 실행
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000` 접속

또는 Node.js가 있다면:

```bash
npx serve .
```

### 방법 B. 파일 직접 열기

`index.html` 파일을 더블 클릭하거나 브라우저로 드래그해서 열어도 대부분의 경우 정상 동작합니다.

## 사용 방법

1. **업로드**: 첫 화면의 드롭존을 클릭하거나 오디오 파일을 드래그 앤 드롭
2. **파형 확인 및 재생**: 업로드 후 파형이 표시되며, 재생/일시정지/정지 버튼과 파형 클릭으로 원하는 위치 탐색 가능
3. **트림**:
   - 파형 위의 좌/우 핸들을 드래그하거나, 시작/끝 시간 입력창에 `mm:ss.cc` 형식(예: `00:12.50`)으로 직접 입력
   - 재생 중 원하는 위치에서 "현재 위치를 시작으로" / "현재 위치를 끝으로" 버튼으로 지점 지정 가능
   - "선택 구간 자르기 적용"을 누르면 실제로 오디오가 잘림 (되돌리려면 "원본으로 되돌리기")
4. **볼륨 조절**:
   - 슬라이더를 움직이면 재생 중인 소리에 실시간으로 반영되어 미리듣기 가능
   - "볼륨 변경 적용"을 눌러야 실제 오디오 데이터에 볼륨 변경이 저장됨 (내보내기에도 반영됨)
5. **내보내기**: 형식(WAV/MP3)과 MP3의 경우 비트레이트를 선택한 뒤 "내보내기" 버튼을 누르면 편집된 오디오가
   다운로드됩니다. 트림과 볼륨 조절을 모두 적용한 뒤 내보내면 편집 결과가 그대로 반영됩니다.

## 기술 스택 및 구조

```
.
├── index.html          # 페이지 구조
├── css/
│   └── style.css        # 스타일
├── js/
│   ├── app.js            # 업로드, 파형 렌더링, 재생, 트림, 볼륨, 인코딩/내보내기 로직
│   └── lib/
│       └── lame.min.js   # MP3 인코딩용 lamejs 라이브러리 (로컬 포함, 오프라인 동작)
└── README.md
```

- **디코딩**: `AudioContext.decodeAudioData` 로 업로드된 오디오(MP3/WAV/OGG 등 브라우저가
  지원하는 포맷)를 `AudioBuffer` 로 디코딩합니다.
- **트림**: `AudioBuffer` 의 채널별 샘플 배열을 원하는 구간만큼 잘라 새로운 버퍼를 생성합니다.
- **볼륨**: 각 샘플 값에 배율을 곱하고 `-1.0 ~ 1.0` 범위로 클리핑하여 새 버퍼를 만듭니다.
- **WAV 내보내기**: `AudioBuffer` 를 16-bit PCM WAV 바이너리로 직접 인코딩합니다(추가 라이브러리 불필요).
- **MP3 내보내기**: [`lamejs`](https://github.com/zhuker/lamejs) 를 이용해 PCM 샘플을 MP3로 인코딩합니다.

## 브라우저 호환성

최신 Chrome, Edge, Safari, Firefox에서 동작합니다. Web Audio API(`AudioContext`,
`decodeAudioData`)를 지원하는 브라우저가 필요합니다.

## 제한 사항

- 브라우저의 오디오 디코더가 지원하는 포맷만 업로드/재생 가능합니다(대부분의 MP3, WAV, OGG, M4A 지원).
- MP3 인코딩은 순수 JS로 동작하기 때문에 파일이 매우 길 경우 내보내기에 다소 시간이 걸릴 수 있습니다.
- 3채널 이상의 멀티채널 오디오는 처음 2채널(스테레오)까지만 처리합니다.
