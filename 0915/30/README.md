# 💣 구슬 대포 추첨기

여러 사람의 이름을 입력하면, 대포에서 구슬을 발사해 페그(핀)와 회전 장애물을
통과시킨 뒤 **가장 마지막에 바닥에 멈춰 서는 구슬**을 당첨자로 뽑아주는
플링코(Plinko) 스타일 추첨 웹 앱입니다.

## 미리보기

- 이름을 하나씩, 또는 쉼표로 구분해 한 번에 여러 명 추가
- "추첨 시작"을 누르면 참가자 수만큼 구슬이 순서대로 발사됨
- 구슬은 랜덤한 각도로 발사되어 페그와 회전 바, 경사 디플렉터에 부딪히며
  무작위로 튕겨 내려감
- 모든 구슬이 바닥에 멈추면, 화면 오른쪽 상단에 당첨자가 표시되고
  왼쪽에는 착지 순서(낙하 순서)가 함께 표시됨
- "같은 명단으로 다시"로 동일 참가자로 재추첨하거나, "명단 다시 입력"으로
  참가자를 새로 구성할 수 있음

## 실행 방법

빌드 과정이 필요 없는 정적 웹 앱입니다. 아래 중 편한 방법으로 실행하세요.

```bash
# 방법 1) 파일을 브라우저에서 바로 열기
open index.html

# 방법 2) 로컬 서버로 실행 (권장 — 일부 브라우저 보안 정책 이슈 방지)
python3 -m http.server 8080
# 이후 브라우저에서 http://localhost:8080 접속
```

인터넷 연결이 필요합니다 (물리 엔진 라이브러리를 CDN에서 불러옵니다).

## 사용 방법

1. 입력창에 이름을 입력하고 `Enter` 또는 "추가" 버튼 클릭
   - 쉼표(`,`)나 줄바꿈으로 구분하면 여러 명을 한 번에 추가할 수 있습니다
   - 이름 칩의 `✕` 버튼으로 개별 삭제, "전체 삭제"로 명단 초기화 가능
2. 참가자가 2명 이상이면 "🎯 추첨 시작" 버튼이 활성화됩니다
3. 버튼을 누르면 대포가 참가자 한 명당 구슬 하나씩 순서대로 발사합니다
4. 모든 구슬이 장애물을 통과해 바닥에 멈추면, 가장 늦게 멈춘 구슬의
   주인이 **당첨자**로 발표됩니다
5. "🔄 같은 명단으로 다시"로 동일 명단으로 재추첨하거나,
   "✏️ 명단 다시 입력"으로 처음 화면으로 돌아갈 수 있습니다

## 당첨자 판정 방식

- 참가자별 구슬은 서로 다른 색으로 구분되며, 발사 순서는 매 추첨마다
  무작위로 섞입니다 (표시되는 명단 순서와는 무관)
- 물리 엔진(Matter.js)으로 각 구슬의 속도를 매 프레임 추적하다가,
  속도가 일정 값 이하로 일정 시간(약 0.75초) 유지되면 "착지 완료"로
  판정합니다
- 모든 구슬이 착지하면, 착지 판정을 가장 나중에 받은 구슬이 당첨자입니다
- 드물게 구슬이 장애물 사이에서 오래 맴도는 경우를 대비해, 마지막 발사
  이후 12초가 지나도 멈추지 않은 구슬은 안전장치로 자동 정산됩니다

## 기술 스택

- Vanilla HTML / CSS / JavaScript (프레임워크 없음, 빌드 불필요)
- [Matter.js](https://brm.io/matter-js/) — 2D 물리 엔진 (중력, 충돌, 회전
  장애물 시뮬레이션), CDN으로 로드
- `<canvas>` 2D API로 대포, 페그, 장애물, 구슬을 직접 렌더링

## 파일 구성

```
index.html   # 페이지 구조 (입력 패널 + 캔버스 스테이지)
style.css    # 다크 테마 UI 스타일
script.js    # 물리 시뮬레이션, 발사/착지 판정, 캔버스 렌더링 로직
README.md    # 이 문서
```

## 커스터마이징 힌트

[script.js](script.js) 상단부의 상수를 조절해 난이도와 연출을 바꿀 수
있습니다.

- `SETTLE_SPEED`, `SETTLE_FRAMES` — 구슬을 "멈췄다"고 판정하는 민감도
- `FIRE_INTERVAL_MS` — 구슬 발사 간격
- `buildWorld()` 내부의 `pegRows`, `cols`, `spinBars`, `deflectors` — 페그
  배열 밀도, 회전 장애물·디플렉터의 개수와 위치
