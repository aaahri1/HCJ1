# PDF 병합기 (PDF Merger)

여러 개의 PDF 파일을 업로드하고, 원하는 순서로 정렬한 뒤 하나의 PDF 문서로 합쳐주는 웹 애플리케이션입니다. HTML, CSS, JavaScript만으로 제작되었으며, 별도의 서버나 백엔드 없이 브라우저 안에서 모든 처리가 이루어집니다.

## 주요 기능

- 클릭 또는 드래그 앤 드롭으로 여러 개의 PDF 파일 업로드
- 업로드한 파일 목록 확인 (파일명, 용량)
- 파일 순서 변경 (위/아래 이동) 및 개별/전체 삭제
- 선택한 순서대로 PDF 병합
- 병합된 PDF 파일 다운로드
- 모든 처리가 브라우저 내에서 수행되어 파일이 서버로 전송되지 않음 (개인정보 보호)

## 사용 기술

- **HTML / CSS / JavaScript** (Vanilla JS, 프레임워크 미사용)
- **[pdf-lib](https://pdf-lib.js.org/)** — 브라우저에서 PDF를 생성/조작하기 위한 JavaScript 라이브러리 (CDN을 통해 로드)

## 파일 구성

```
27/
├── index.html   # 페이지 구조
├── style.css    # 스타일
├── script.js    # PDF 업로드 및 병합 로직
└── README.md
```

## 실행 방법

별도의 빌드나 설치 과정이 필요 없습니다.

1. `index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 엽니다.
2. 드래그 앤 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF 파일들을 업로드합니다.
3. 목록에서 ▲ / ▼ 버튼으로 병합 순서를 조정하고, 필요 없는 파일은 ✕ 버튼으로 삭제합니다.
4. **PDF 병합하기** 버튼을 클릭합니다.
5. 병합이 완료되면 **병합된 PDF 다운로드** 버튼을 눌러 결과 파일(`merged.pdf`)을 저장합니다.

> 참고: 파일을 `file://` 경로로 직접 열어도 동작하지만, 브라우저 보안 정책에 따라 일부 환경에서 제약이 있을 수 있습니다. 문제가 발생하면 간단한 로컬 서버(`python3 -m http.server` 등)를 사용해 실행해 보세요.

## 유의사항

- 업로드는 `.pdf` 확장자 또는 `application/pdf` MIME 타입의 파일만 허용됩니다.
- 최소 2개 이상의 PDF 파일을 업로드해야 병합 버튼이 활성화됩니다.
- 암호로 보호되어 있거나 손상된 PDF 파일은 병합에 실패할 수 있으며, 이 경우 오류 메시지가 표시됩니다.
- 인터넷 연결이 필요합니다 (pdf-lib 라이브러리를 CDN에서 불러오기 때문입니다).
