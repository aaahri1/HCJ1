# BMI 계산기

키, 몸무게, 성별을 입력하면 BMI와 비만도를 계산하고, 표준체중을 기준으로 90% / 100% / 110%에 도달하기 위해 감량 또는 증량해야 할 체중(kg)을 알려주는 웹 앱입니다.

## 실행 방법

별도의 빌드나 설치 과정 없이 HTML/CSS/JS로만 동작합니다.

1. 이 폴더에서 로컬 서버를 실행합니다.

   ```bash
   python3 -m http.server 8000
   ```

2. 브라우저에서 `http://localhost:8000` 에 접속합니다.

또는 `index.html` 파일을 브라우저에서 바로 열어도 동작합니다.

## 사용 방법

1. 키(cm), 몸무게(kg), 성별을 입력합니다.
2. "계산하기" 버튼을 누르면 아래 정보가 표시됩니다.
   - 현재 BMI 수치와 비만도 분류(저체중 / 정상 / 과체중 / 비만)
   - 표준체중(kg)
   - 표준체중의 90% / 100% / 110% 기준 목표 체중과, 현재 체중에서 얼마나 감량 또는 증량해야 하는지

## 계산 공식

- **BMI** = 몸무게(kg) ÷ 키(m)²
- **BMI 분류** (아시아-태평양 기준)
  - 18.5 미만: 저체중
  - 18.5 ~ 22.9: 정상
  - 23 ~ 24.9: 과체중
  - 25 이상: 비만
- **표준체중(kg)** = 키(m)² × 22 (남성) / × 21 (여성)
- **목표 체중** = 표준체중 × (90% / 100% / 110%)
- **감량/증량(kg)** = 목표 체중 − 현재 체중 (음수면 감량, 양수면 증량 필요)

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 입력 폼과 결과를 표시하는 화면 구조 |
| `style.css` | 화면 스타일 |
| `script.js` | BMI 및 목표 체중 계산 로직 |

## 참고

- 표준체중 계산에 사용하는 22(남성) / 21(여성) 계수는 국내에서 흔히 쓰이는 방식이며, 의학적 진단을 대체하지 않는 참고용 수치입니다.
