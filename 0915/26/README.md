# Lorem Ipsum 생성기

슬라이더(또는 숫자 입력)로 원하는 글자 분량을 지정하면 그에 맞는 Lorem Ipsum 텍스트를 즉시 생성해주는 웹 앱입니다.

## 주요 기능

- 기본 150자 분량의 Lorem Ipsum 텍스트를 바로 표시
- 슬라이더를 움직이면 실시간으로 글자 분량이 반영된 텍스트 재생성
- 슬라이더 옆 숫자 입력창으로 정확한 글자 수 직접 입력 가능
- 최소 10자, 최대 5000자 범위 제한
- 생성된 텍스트를 클립보드로 복사하는 버튼 제공
- 라이트/다크 모드 자동 대응

## 사용 방법

1. `index.html` 파일을 브라우저로 엽니다. (별도 설치나 빌드 과정 필요 없음)
2. 화면의 슬라이더를 좌우로 움직이거나 숫자 입력창에 값을 입력합니다.
3. 입력한 글자 수에 맞춰 텍스트 영역의 내용이 자동으로 갱신됩니다.
4. "복사" 버튼을 눌러 생성된 텍스트를 클립보드에 복사할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조 (슬라이더, 입력창, 결과 영역) |
| `style.css` | 스타일링 (레이아웃, 다크모드 대응) |
| `script.js` | Lorem Ipsum 생성 로직 및 이벤트 처리 |

## 동작 원리

`script.js`의 `buildLoremText(targetLength)` 함수가 정해진 Lorem Ipsum 단어 목록을 조합해 문장과 문단을 생성하면서, 목표 글자 수(`targetLength`)에 도달할 때까지 텍스트를 누적합니다. 목표 글자 수를 넘어서면 정확히 해당 길이로 잘라내어 슬라이더 값과 실제 출력 글자 수가 일치하도록 합니다.

## 브라우저 호환성

최신 버전의 Chrome, Safari, Edge, Firefox에서 동작을 확인했습니다. 별도의 외부 라이브러리나 프레임워크 없이 순수 HTML/CSS/JavaScript로 작성되었습니다.
