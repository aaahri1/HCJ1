# 자리비움 안내판 (Away Screen)

잠시 자리를 비울 때 화면에 안내 정보를 표시해 주는 웹 앱입니다.
설치나 빌드 과정 없이 브라우저만 있으면 바로 사용할 수 있습니다.

## 미리보기 흐름

1. **입력 화면**: 일정 / 돌아오는 시간 / 기타 문구를 입력합니다.
2. **확인 버튼**을 누르면 화면을 가득 채우는 그라데이션 애니메이션이 재생되며 안내 화면으로 전환됩니다.
3. **안내 화면**: 입력한 일정이 가장 큰 글자로 표시되고, 그 아래 복귀 예정 시각과 실시간 카운트다운, 기타 문구가 함께 출력됩니다. 배경은 계속 부드럽게 움직이는 그라데이션으로 채워져 있습니다.

## 기능

- **일정 표시**: 화면에서 가장 큰 글씨로 강조 표시 (예: `회의중`, `점심시간`, `외근중`)
- **자유로운 시간 입력**: `14:30`, `1430`, `14.30`, `14시 30분`, `14시`처럼 원하는 형식으로 자유롭게 타이핑할 수 있고, `10분 후` / `30분 후` / `1시간 후` / `2시간 후` 버튼으로 현재 시각 기준 빠르게 채울 수도 있습니다.
- **복귀 시간 & 카운트다운**: 입력한 시각까지 남은 시간을 `HH:MM:SS` 형식으로 1초 단위로 갱신하여 보여줍니다. 복귀 시각이 지나면 자동으로 "경과 시간"으로 전환되어 얼마나 지났는지 보여줍니다.
- **기타 문구**: 연락처, 요청 사항 등 자유롭게 입력한 안내 문구를 함께 표시합니다.
- **전환 애니메이션**: 확인 버튼을 누르면 그라데이션이 원형으로 화면을 덮으며 자연스럽게 안내 화면으로 전환됩니다.
- **배경 애니메이션**: 안내 화면 배경은 색이 서서히 흐르듯 움직이는 그라데이션 + 은은한 블러 도형으로 구성되어 있습니다.
- **전체화면 모드**: 우측 상단 ⛶ 버튼으로 전체화면 전환 (모니터에 띄워두기 좋습니다).
- **수정하기**: 우측 상단 ✎ 버튼 또는 `Esc` 키로 언제든 입력 화면으로 돌아가 내용을 다시 설정할 수 있습니다.
- **새로고침 복원**: 안내 화면을 띄운 상태에서 브라우저를 새로고침해도 입력했던 내용과 카운트다운이 그대로 유지됩니다 (브라우저 `localStorage` 사용, 기기 로컬에만 저장되며 외부로 전송되지 않습니다).

## 사용 방법

별도 설치 없이 `index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.

```bash
open index.html
```

또는 로컬 서버로 실행하고 싶다면:

```bash
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

1. **일정**을 입력합니다. (필수, 예: `회의중`)
2. **돌아오는 시간**을 입력합니다. (필수, `14:30` / `1430` / `14시 30분` 등 자유 형식 지원, 빠른 선택 버튼 사용 가능 / 이미 지난 시각을 입력하면 다음날 같은 시각으로 자동 계산됩니다)
3. **기타 문구**를 입력합니다. (선택, 예: `급한 용무는 010-1234-5678로 연락주세요`)
4. **확인** 버튼을 눌러 안내 화면을 띄웁니다.
5. 자리로 돌아오면 ✎ 버튼(또는 `Esc`)을 눌러 다음 자리비움을 위해 새로 입력할 수 있습니다.

## 파일 구성

```
├── index.html   # 입력 화면 / 안내 화면 마크업
├── style.css    # 레이아웃, 그라데이션 애니메이션, 반응형 스타일
├── script.js    # 입력 검증, 화면 전환, 카운트다운, 로컬 저장 로직
└── README.md
```

## 기술 스택

순수 HTML / CSS / JavaScript (바닐라, 별도 프레임워크·빌드 도구 없음). 한글 및 숫자 가독성을 위해 Google Fonts의 `Noto Sans KR`, `Poppins`를 사용합니다 (인터넷 연결 필요, 연결이 없으면 시스템 기본 글꼴로 대체됩니다).

## 브라우저 지원

최신 Chrome, Edge, Safari, Firefox 등 evergreen 브라우저에서 동작을 확인했습니다. 전체화면 기능은 Fullscreen API를 지원하는 브라우저에서만 동작합니다.
