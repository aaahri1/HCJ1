# 오늘의 원소 운세

이름, 생일, 성별을 입력하고 물 / 불 / 나무 / 땅 / 바람 중 하나를 선택하면
오늘의 운세를 랜덤으로 보여주는 정적 웹사이트입니다.

## 기능

- 이름 / 생일 / 성별 입력 폼
- 5가지 원소(물, 불, 나무, 땅, 바람) 중 하나 선택
- 선택한 원소에 맞는 운세 문구를 랜덤으로 출력
- 행운의 색 / 행운의 숫자 / 행운의 아이템을 함께 표시
- "다시하기" 버튼으로 재입력 가능
- 라이트/다크 모드 자동 대응, 모바일 폭에서도 정상 표시되는 반응형 레이아웃

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 입력 폼과 결과 화면 마크업 |
| `style.css` | 전체 스타일 (라이트/다크 테마, 반응형) |
| `script.js` | 원소 선택, 운세 랜덤 추첨, 결과 렌더링 로직 |

## 실행 방법

별도의 빌드 과정 없이 정적 파일만으로 동작합니다.

1. 이 폴더에서 로컬 서버를 실행합니다.

   ```bash
   python3 -m http.server 8000
   ```

2. 브라우저에서 `http://localhost:8000` 접속합니다.

또는 `index.html` 파일을 브라우저에 직접 드래그해서 열어도 됩니다.

## 사용 방법

1. 이름, 생일, 성별을 입력합니다.
2. 물 / 불 / 나무 / 땅 / 바람 중 오늘의 원소를 하나 선택합니다.
3. "운세 보기" 버튼을 누르면 선택한 원소에 해당하는 운세 문구 중 하나가
   랜덤으로 뽑혀 행운의 색/숫자/아이템과 함께 표시됩니다.
4. "다시하기" 버튼을 누르면 입력 폼으로 돌아가 다시 시도할 수 있습니다.

## 운세 로직

- 원소별로 5개씩 준비된 운세 문구 중 하나를 `Math.random()`으로 무작위 선택합니다.
- 행운의 색(10종) / 행운의 아이템(10종) / 행운의 숫자(1~45)도 매번 랜덤으로 결정됩니다.
- 실제 사주나 점성술 이론에 근거한 것이 아닌 재미로 즐기는 콘텐츠입니다.
