# 글자수 세기

텍스트를 입력하면 실시간으로 글자수와 byte 수를 계산해 주는 단일 페이지 웹 도구입니다.

- 데모(Artifact): https://claude.ai/artifact/BNeDkSMuiAreJYg2Pq79Qu

## 기능

- 전체 글자수 (공백 포함)
- 공백 제외 글자수
- 단어수
- Byte 수

## Byte 계산 규칙

- 영문, 숫자, 공백, 기호 등 아스키(ASCII, 코드값 0x7F 이하) 문자: **1byte**
- 한글, 한자, 이모지 등 아스키 범위를 벗어나는 문자: **2byte**

자기소개서, 이름, 주소처럼 byte 단위로 글자 수 제한이 걸린 입력칸의 길이를 미리 확인할 때 사용할 수 있습니다.

## 실행 방법

별도 설치나 빌드 과정 없이 `index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.

```bash
open index.html
```

## 구조

| 파일 | 설명 |
| --- | --- |
| `index.html` | 입력창, 통계 표시, byte 계산 로직을 포함한 단일 HTML 파일 |

모든 계산은 브라우저 내에서만 이루어지며, 입력한 텍스트는 외부로 전송되지 않습니다.
