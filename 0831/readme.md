
# K-MOVE 동아리 MT 안내 웹앱

Google Apps Script(GAS)로 만든 K-MOVE 동아리 MT 안내 웹앱입니다.

---

## 1. 프로젝트 개요

- **목적**: 해외취업을 준비하는 K-MOVE 동아리원들에게 MT 일정, 준비물, 장소, 유의사항을 한 페이지로 안내
- **일시/장소**: 9월 19일(토) ~ 20일(일), 경남 거제 오션뷰 펜션 (예시 데이터)

---

## 2. 기술 스택

- **런타임**: Google Apps Script (HtmlService)
- **마크업/스타일**: HTML5, CSS

---

## 3. 파일 구성

```text
.
├── Code.gs      # 웹앱 진입점(doGet) - index.html 렌더링
├── index.html   # MT 안내 페이지
└── readme.md
```

---

## 4. 배포 방법

1. script.google.com 에서 새 프로젝트 생성
2. 기본 파일에 `Code.gs` 내용 붙여넣기
3. 파일 추가 > HTML > 파일명을 `index`로 저장하고 `index.html` 내용 붙여넣기
4. 배포 > 새 배포 > 유형: 웹 앱
   - 실행 계정: 나
   - 액세스 권한: 모든 사용자(또는 필요에 맞게 조정)
5. 배포 후 생성되는 URL로 접속

---

## 5. 주요 페이지 구성

1. **SCHEDULE**: Day 1(집합/이동/세션/레크리에이션), Day 2(발표/정리/귀가) 시간표
2. **CHECKLIST**: 신분증, 세면도구, 여벌 옷 등 준비물 체크리스트
3. **LOCATION**: 집합 장소 및 MT 장소, 이동 수단, 문의처
4. **NOTICE**: 참가비 입금 안내, 음주 관련 안전 수칙, 불참 시 연락 기준
