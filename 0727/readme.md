
# 이유정 | UI/UX Designer Portfolio

UI/UX 디자이너를 지향하는 이유정의 포트폴리오 웹페이지입니다.

---

## 1. 프로젝트 개요

- **목적**: UX/UI 분석과 에디토리얼 디자인 역량을 중심으로 한 포트폴리오 소개, 일본 디자인 업계 진출을 목표로 한 어필 페이지
- **구성**: About - Portfolio - Skills 3개 섹션 원페이지 구조
- **특징**: PDF 이력서 다운로드, 메일 보내기 버튼 등 실질적인 컨택 기능 포함

---

## 2. 기술 스택

- **마크업**: HTML5
- **스타일링**: CSS3
- **에셋**: 프로젝트별 커버 이미지, 포스터/일러스트 실사 이미지

## 6. 실행 방법

별도 설치 과정 없이 `index.html`을 브라우저에서 바로 열면 됩니다.

```bash
python3 -m http.server 8080
```

실행 후 `http://localhost:8080` 접속하여 확인합니다.
