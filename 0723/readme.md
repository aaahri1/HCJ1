
# 이유정 | 시각디자인 포트폴리오

시각디자인 전공자 이유정의 개인 포트폴리오 단일 페이지 웹사이트입니다.

---

## 1. 프로젝트 개요

- **목적**: 브랜드 아이덴티티, 포스터, 일러스트 등 시각디자인 작업물을 한 페이지에 정리해 보여주는 포트폴리오
- **구성**: About(소개) - Portfolio(작업물) - Contact(연락처) 3개 섹션으로 이루어진 원페이지 스크롤 구조
- **특징**: 이미지 클릭 시 원본을 확대해서 보여주는 모달(라이트박스) 기능 포함

---

## 2. 기술 스택

- **마크업**: HTML5
- **스타일링**: CSS3 (Pretendard 웹폰트, CSS 변수 기반 색상 관리)
- **스크립트**: Vanilla JavaScript (이미지 모달 열기/닫기)

---

## 5. 실행 방법

별도 설치 과정 없이 `index.html`을 브라우저에서 바로 열면 됩니다.

```bash
python3 -m http.server 8080
```

실행 후 `http://localhost:8080` 접속하여 확인합니다.
