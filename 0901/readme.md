
# 교육자료 사용 후기 조사

Google Apps Script(GAS)로 만든 교육자료 사용 후기 설문조사 웹앱입니다. 제출된 응답은 Google 스프레드시트에 자동으로 누적됩니다.

---

## 1. 프로젝트 개요

- **목적**: 학부 및 대학원생 대상으로 교육자료(강의안, 영상, 실습자료 등) 활용 현황과 만족도를 조사
- **응답 저장 방식**: 클라이언트에서 입력한 설문 데이터를 `submitForm()` 함수로 전달받아 지정된 스프레드시트에 한 줄씩 추가

---

## 2. 기술 스택

- **런타임**: Google Apps Script (HtmlService, SpreadsheetApp)
- **마크업/스타일**: HTML5, CSS
- **연동**: Google Sheets

---

## 3. 파일 구성

```text
.
├── Code.gs      # 웹앱 진입점(doGet) 및 응답 저장 함수(submitForm)
├── index.html   # 설문조사 페이지
└── readme.md
```

---

## 4. 배포 방법

1. 응답을 저장할 Google 스프레드시트를 만들고, URL에서 `/d/`와 `/edit` 사이의 스프레드시트 ID를 확인
2. `Code.gs`의 `SPREADSHEET_ID`에 위 ID 값 입력, `SHEET_NAME`은 실제 시트 이름과 일치시킴
3. script.google.com 에서 새 프로젝트 생성 후 `Code.gs`, `index.html` 내용을 각각 붙여넣기
4. 배포 > 새 배포 > 유형: 웹 앱으로 배포
5. 배포된 URL로 접속하여 설문 응답 접수 확인

---

## 5. 주요 설문 항목

1. **기본 정보**: 학번, 이름
2. **전반적인 만족도**: 매우 불만족 ~ 매우 만족 5단계 평가
3. **주로 이용한 교육자료 종류**(중복 선택): PDF 강의안, 동영상 강의, 실습 코드, 참고 논문, 퀴즈/과제, 기타
4. 제출 시 스프레드시트에 학번/이름/만족도/자료유형/제출시각이 한 줄로 기록됨
